# Product

## Purpose

Help a person see what money represents to them, how they emotionally relate to it,
and where their stated values, behaviors, and financial reality differ.

## Product principle

A mirror, not a scorecard.

## V1 user flow

Landing page
→ anonymous assessment
→ deterministic scoring
→ deterministic results
→ optional AI synthesis
→ report
→ optional email/save/share
→ feedback

## V1 exclusions

Do not add:
- paid subscriptions
- user accounts unless necessary for persistence
- couples comparison
- advisor portal
- coaching
- financial recommendations
- gamification
