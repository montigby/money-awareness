# Assessment V1

Core dimensions:

1. Internal Security
2. Enoughness
3. Identity Attachment
4. Need for Control
5. Freedom Orientation
6. Present Enjoyment

Additional:
- Chosen Money Attention
- Compelled Money Attention
- Behavioral scenarios
- Optional financial context
- Optional reflection

The canonical question configuration is `lib/assessment/questions.ts`.

Question IDs are stable API/data identifiers. Do not rename them casually.

Psychometric items use a 1–7 Likert scale.

Financial context must remain optional so the core assessment can still complete
without forcing disclosure of financial information.
